# Contributing

Use Node 24 and an isolated Python 3.12–3.14 environment. Install the locks, run the full README verification commands, and add regression tests for every fixed defect/new format. Keep synthetic fixtures free of real names, confidential documents and secrets.

Maintain server-side authorization, HTML-first exports, exact-cent reporting, dimensional unit checks, bounded work and uncertainty/provenance. Add no language/framework/service without a specific technical purpose. Prefer descriptive names, explicit schemas and standard-library algorithms. Keep module headers and function/class contracts useful; regenerate `python scripts/code_index.py` after formatting so exact line maps remain current.

Do not suppress security/coverage failures or broaden ACLs just to pass tests. Provider/network tests should use explicit fake contracts; real integrations require consent, credential handling and separate quality evaluation. Update format/operations/API docs and reports when behavior changes. PR workflows run with read-only content permissions; security analysis writes only its findings.
