# Business Knowledge Workbench 1.1.0

Private local document and business-data workspaces by Jason Stys.

Adds real local accounts, independent vault phrases, per-session unlock proof, AES-256-GCM locked documents/settings, scoped encrypted snapshots, login recovery, current-password-confirmed own-account deletion, idle locking and explicit own model destination consent. Existing HTML-first rich imports, unit normalization, products, sales reporting, document search/compilation and exports remain functional. Fictional examples are explicit opt-in; no demo passwords are used by installed accounts.

Windows x64 per-user setup/portable ZIP, macOS arm64 DMG/portable archive, and Linux x64 AppImage/portable archive include the Python document service, UI and dependency notices. Checksum files use the exact GitHub download filenames. Each packaged app is tested with genuine authentication, WebCrypto, rich DOCX conversion, scriptless preview, JSON download, synthetic reporting and encryption.

Local-only, one unlocked account engine. No public hosting/shared-team invitations, native phone packages or universal document/image interpretation. Desktop binaries are unsigned/not notarized. Active processing requires trusting the OS and local service; locked archives do not protect against malware/administrators. External AI is off by default and any deliberate provider use is subject to provider retention/costs. Existing legacy data is preserved separately.

See README, docs/private-accounts.md, docs/validation-v1.1.md and SECURITY.md for usage and exact evidence.
