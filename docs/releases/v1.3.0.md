# Business Knowledge Workbench 1.3.0 — searchable standardized library

Created by Jason Stys. Browse, upload, preview, search and download standardized
business files using the same private local account application on desktop or in
its local browser website.

- Permission-scoped, paginated file library with titles/excerpts, categories,
  source types, review states, timestamps and standard revisions.
- Combined content, format, table, dimension, access, review and field-value
  filters. Counts and suggestions share document authorization.
- Direct standard downloads and original/source comparison in document details.
- Visual field add/remove/reorder/exclude controls, explicit unknown-column
  omission and preserved source evidence.
- Real-file, non-persistent standard previews; margins, alignment, spacing,
  running header/footer and DOCX/PDF page-number settings.
- Detected PDF tables no longer appear a second time as prose; generated DOCX
  settings and geometry are validated more strictly.
- Realistic manufacturing, renewable-energy and calibration-laboratory oracles
  across eight tabular source formats and all six output types, plus role,
  browser, accessibility and actual packaged-app regressions.
- Patched Electron/Python dependencies, explicit Windows desktop shortcut,
  native-package PR checks and bounded CI jobs.

Accounts and encrypted vaults remain outside the repo and installer. Private mode
is local and owner-only; role previews do not create coworkers or cloud hosting.
Field exclusion is not redaction; original/source blocks remain downloadable.
PDF/table/graph interpretation requires review; there is no universal OCR or full
Word layout engine. The app does not send documents to AI without explicit
provider consent.

Installers include the service and UI; normal use requires no terminal setup.
Windows per-user setup creates a desktop icon. Linux x64 and macOS arm64 packages
are also produced and tested. Packages remain unsigned/not notarized. Keep OS
protections enabled; close and back up the entire private account directory
before upgrading. All exact-source CI, CodeQL and native-package gates must pass
before this release is published.
