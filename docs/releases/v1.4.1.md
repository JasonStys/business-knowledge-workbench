# Business Knowledge Workbench 1.4.1

By Jason Stys. This maintenance release keeps the existing configurable standards,
unit normalization, permitted document library, numeric search and ZIP downloads.
It repairs damaged Unicode punctuation in product lists and document previews.
Browser regressions verify the actual visible arrow, separator and preview text,
rather than accepting an ASCII substitute or a malformed byte sequence.

The desktop bundles Python 3.14.10 and Electron 44.11.0. Frozen services refuse a
different interpreter before private account setup or conversion-child dispatch;
health and native acceptance identify the interpreter actually in use. Source
development retains the declared Python compatibility range. The Python security
update is described in its [official release notice](https://www.python.org/downloads/release/python-31410/).

The native journey now closes the application, starts it again, authenticates the
same synthetic account, unlocks the same vault and compares the retained library
records. This tests persistence beyond merely opening a second process. Existing
accounts and vault formats do not change. Quit the old app cleanly and back up its
private data before upgrading; private data remains outside the installation and
repository. The installer retains the same application identity and shortcut.

Release automation assembles a draft only after exact-main validation, native
packages and complete CodeQL gates. It checks numeric draft identity, rejects tag
collisions and verifies all twelve expected binaries/checksums. Independent final
download, extraction and installer acceptance precede publication. Nothing in the
draft-verification job publishes a release. Historical 1.4.0 assets and dated
reports remain unchanged. Packages are unsigned and are not claimed to be notarized.
