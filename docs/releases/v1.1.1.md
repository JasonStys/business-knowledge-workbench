Private local business documents and reporting by Jason Stys. A deterministic delayed-audit test verifies the first-view readiness boundary before a real rich-document import/export journey.

No hosted service/shared-team permissions/native phone installation or universal OCR interpretation is introduced.

Use the same independent vault phrase and private account directory. Existing 1.1.0 downloads are retained for provenance, not silently replaced. See docs/validation-v1.1.md for the patch's verified CI and independently downloaded Windows results.
