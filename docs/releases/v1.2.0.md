# Business Knowledge Workbench 1.2.0 — governed output standards

Created by Jason Stys. Standardize supported business documentation and data into
consistent units, field structure, document organization and delivery formats.

- Owner/admin-controlled named standards, safe layout/heading settings and optional
  preferred-format enforcement on the server.
- Canonical table fields, aliases and order, required/optional values, explicit
  dimensional units and preserve/reject rules for extra fields.
- Non-persistent CSV draft preview, transactional publication, revision history
  and restoration as a new revision.
- Current-standard source copies and consistently normalized compilations without
  rewriting originals, repeatedly rounding preserved source blocks or replaying sales.
- Standard-format, account-scoped business report downloads.
- Expanded real parser, API/authorization, browser and native application tests;
  original-purpose review and detailed standards guide.

Private accounts remain local, independently encrypted and outside Git. No cloud
host, team invitations, arbitrary code/template execution, automatic AI sharing or
universal OCR/file interpretation is added. Existing private data is preserved;
close and back up the entire private account directory before upgrading. Paper/font
presentation is simplified, not a guarantee of lossless source formatting.

Downloads are unsigned and not notarized; hashes are not publisher signatures.
Never disable OS/browser protections to launch a package. Use the existing app
with real account data only after reviewing its privacy/format limits. All package
targets must pass the source gates and their actual packaged-app workflow before
this draft Release is published.
