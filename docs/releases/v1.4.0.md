# Business Knowledge Workbench 1.4.0 — quantitative search and evidence packs

Created by Jason Stys. Search standardized measurements across compatible units
and saved standard revisions, then gather selected permitted files in a bounded
ZIP using each file's saved output policy. The integrity manifest records order,
file/standard hashes and byte counts. Original attachments and account material
are excluded; exported business data remains plaintext and needs protection.

Numeric ranges are inclusive and field/cell-bound. Unitless comparisons never
infer units; missing or incompatible values do not become zero. No source
document, sales record or standard revision is rewritten by searching/exporting.

Scientific-notation and leading-decimal measurements now normalize as complete
numbers. Regression tests prevent mistakenly converting only an exponent suffix;
ambiguous embedded identifiers and hyphenated ranges remain unchanged for review.

Private owner accounts, encrypted locking and explicit model-provider consent
remain in force. The app is local, with a local browser view; there is no shared
team/cloud hosting, universal OCR or arbitrary executable template support.
Packages are unsigned/not notarized. Close the app and back up the entire private
account directory before upgrading; retain OS protections. Release publication
requires exact-source validation, security and genuine three-OS package gates.
