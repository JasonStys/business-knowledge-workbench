## Regressions corrected during implementation

- DOCX paragraphs without a declared style now fall back safely; generic Office Math elements serialize via lxml rather than assuming a wrapper-only property.
- HTML active/remote content is removed; canonical preview has a scriptless sandbox and HTML exports retain their restrictive CSP.
- Unit names cannot cross dimensions; nonfinite/over-precision values and physically impossible temperatures are rejected. An ambiguous English `in` phrase is preserved rather than misconverted.
- Sales imports commit atomically, distinguish document imports from sales imports and reject duplicate source application even after config/visibility changes. Imports reserve a SQLite write lock and recheck after conversion.
- Low-contrast labels and the hidden mobile scenario label were fixed using browser evidence.
- PWA navigation uses a network-only request so browser HTTP cache does not mask the safe offline fallback. Business/API responses never enter the service-worker cache.
- Generated line maps use actual compiler source input and explicit UTF-8, preventing stale line numbers or Windows encoding drift. SQLite backup connections are explicitly closed.
- CodeQL identified a user-influenced preview URL interpolated into HTML and a whitespace-regex backtracking risk. Preview URLs now use DOM properties/URL encoding; workspace selection is allowlisted. The ambiguity guard scans whitespace linearly. Adversarial DOM selection and 150,000-space unit regressions pass; both alerts were fixed by source changes, not dismissed.
- CSV fixture generation uses explicit LF output, preventing doubled carriage returns on Windows. The tracked-file catalog is generated and checked alongside exact code line maps.
